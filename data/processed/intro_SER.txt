# Speech Emotion Recognition (SER) — 語音情緒辨識

## 什麼是 SER？

語音情緒辨識（Speech Emotion Recognition, SER）是一種從語音訊號中自動偵測說話者情緒狀態的技術。SER 系統分析語音的聲學特徵，輸出對應的情緒類別或情緒維度值，無需依賴語音的文字內容。

SER 回答的問題是：**「這個人說話時的情緒是什麼？」**

## SER 在 Cascade Pipeline 中的角色

在 Cascade 語音虛擬病人系統中，SER 與 ASR 同時處理使用者的語音輸入：

```
使用者語音

↓（VAD 過濾後）

┌──────────────────────────┐

│ [ASR] → 文字（說了什麼） │ ← 平行處理

│ [SER] → 情緒（語氣如何） │

└──────────────────────────┘

↓

[LLM + RAG] 整合文字 + 情緒

↓

[TTS] 合成帶情緒的語音回應
```

**SER 在虛擬病人系統的具體功能：**
- 偵測醫學生說話時的情緒（緊張、冷靜、困惑、沮喪）
- 將情緒標籤傳遞給 LLM，讓虛擬病人能調整回應風格
- 提供情緒資訊給 TTS，讓病人語音的情感表達更真實

## 情緒的表示方式

### 1. 類別式情緒（Categorical Emotions）
將情緒分為有限的離散類別，是最常見的 SER 任務：

| 常見情緒類別 | 說明 |
|---|---|
| Neutral（中性）| 無明顯情緒 |
| Angry（憤怒）| 語氣強烈、音調高 |
| Sad（悲傷）| 語速慢、音調低 |
| Happy（快樂）| 語速快、音調高且多變 |
| Fearful（恐懼）| 語速快、音量小 |
| Disgust（厭惡）| 語氣低沉 |
| Surprised（驚訝）| 音調突然升高 |

### 2. 維度式情緒（Dimensional Emotions）
用連續數值描述情緒的強度，更細緻但難以標註：

- **Arousal（喚醒度）**：情緒的激烈程度（平靜 ↔ 激動）
- **Valence（效價）**：情緒的正負向（負面 ↔ 正面）
- **Dominance（支配感）**：說話者的主控感（被動 ↔ 主導）

評估維度式情緒通常使用 **CCC（Concordance Correlation Coefficient）** 而非準確率。

## 主要技術方法演進

### 第一代：手工特徵 + 傳統機器學習
使用人工設計的聲學特徵（pitch、MFCC、能量、語速）搭配 SVM、HMM 分類器。代表工具為 **openSMILE**，其 eGeMAPS 特徵集包含 88 維精心設計的聲學參數。

**優點**：可解釋性高、計算輕量
**缺點**：特徵工程複雜、泛化能力有限、在自然語音上準確率偏低

### 第二代：深度學習端對端
使用 CNN、RNN/LSTM 直接從 mel-spectrogram 學習特徵，減少手工設計需求。

**優點**：自動學習特徵
**缺點**：需要大量標註資料，資料取得困難

### 第三代：自監督預訓練模型（當前 SOTA）
以 wav2vec 2.0、HuBERT 等大型自監督模型為特徵提取器，僅需少量標註資料即可 fine-tune 出高效能 SER 模型。這是目前業界主流方法。

**優點**：準確率高、低資源情境仍有效、可遷移到不同語言
**缺點**：模型較大、推論時間較長

## 核心模型介紹

### wav2vec 2.0（Baevski et al., 2020）
Facebook AI Research 提出的自監督語音表示學習框架。

- **arXiv**: 2006.11477
- **架構**：CNN 特徵提取器 → Transformer 上下文編碼器 → 量化模組
- **預訓練方式**：遮蔽部分輸入（類似 BERT 的 masked prediction），在未標註語音上自監督訓練
- **SER 應用**：凍結或微調 wav2vec 2.0，接上輕量分類頭即可達到 SOTA 效果
- **在 IEMOCAP 上的表現**：Unweighted Accuracy (UA) 可達 65–73%，視 fine-tuning 策略而定

### HuBERT（Hsu et al., 2021）
類似 BERT 的語音預訓練模型，透過離線聚類（K-means）產生偽標籤進行自監督訓練。

- 在 SER 任務上與 wav2vec 2.0 效果相當，維度預測（Arousal/Valence）表現更穩定
- 更適合需要連續情緒維度輸出的應用場景

### emotion2vec
專門針對情緒辨識任務設計的預訓練模型，在多種語言上取得 SOTA 表現，對中文語音的情緒辨識效果較 wav2vec 2.0 更好，是中文虛擬病人場景的優先選項。

### openSMILE + 傳統特徵（傳統方法）
openSMILE 是最廣泛使用的語音特徵萃取工具，提供多種標準特徵集：

| 特徵集 | 維度 | 適用情境 |
|---|---|---|
| **eGeMAPS** | 88 維 | 研究標準，可解釋性高 |
| **ComParE** | 6373 維 | 競賽用，覆蓋最全面 |
| **GeMAPS** | 62 維 | 輕量版，即時系統 |

## Fine-tuning 策略

針對 wav2vec 2.0 在 SER 任務上的 fine-tuning，有三種主要策略：

| 策略 | 說明 | 適合情境 |
|---|---|---|
| **V-FT（Vanilla Fine-tuning）** | 直接在目標情緒資料集上微調 | 有足夠標註資料 |
| **TAPT（Task Adaptive Pretraining）** | 先在未標註目標語音上繼續預訓練，再 fine-tune | 有大量未標註語音 |
| **P-TAPT（Pseudo-label TAPT）** | 對未標註資料產生偽標籤後做 TAPT | 低資源、無標註資料（醫療場景常見）|

**醫療場景建議使用 P-TAPT**，因為醫療語音的情緒標註資料極少，但未標註的醫療對話語音可以收集。

## 常用評估資料集

| 資料集 | 語言 | 情緒類別數 | 特色 |
|---|---|---|---|
| **IEMOCAP** | 英文 | 4–8 類 | 最常用 SER benchmark，雙人對話情境 |
| **RAVDESS** | 英文 | 8 類 | 演員錄音，音質高，常用於快速驗證 |
| **MSP-Podcast** | 英文 | 連續維度 | 自然語音，帶 A/D/V 標註，最貼近真實場景 |
| **EmoDB** | 德文 | 7 類 | 較早期的經典資料集 |
| **SAVEE** | 英文 | 7 類 | 男性說話者 |

**中文 SER 資料集目前嚴重缺乏**，這是整個領域的已知瓶頸，也是中文虛擬病人系統的主要技術限制之一。

## 評估指標

| 指標 | 說明 | 使用情境 |
|---|---|---|
| **WA（Weighted Accuracy）** | 加權準確率，考慮類別不平衡 | 類別分布不均時 |
| **UA（Unweighted Accuracy）** | 各類別準確率的算術平均 | 衡量少數情緒類別的辨識效果 |
| **CCC（Concordance Correlation Coefficient）** | 衡量預測與標準的一致性 | 連續維度（Arousal/Valence）評估 |

在 IEMOCAP 上，SOTA 系統的 UA 約為 70–75%（4分類）。

## SER 在虛擬病人系統的整合方式

### 情緒標籤整合進 LLM Prompt

SER 的輸出作為額外的上下文資訊，直接嵌入 LLM 的 Prompt 中：

```
[學生當前情緒狀態（由 SER 分析）]
情緒：緊張（信心度：0.82）
回應策略：學生語氣緊張，病人可以放慢說話節奏，給予安撫性回應
```

### 情緒資訊回饋 TTS 風格

SER 的輸出不只影響 LLM 的文字生成，也可以控制 TTS 合成語音的情感風格：

| 學生情緒 | 病人 TTS 回應風格 |
|---|---|
| 緊張（Fearful）| 語速放慢、音調溫和 |
| 憤怒（Angry）| 病人可能更焦慮、語速加快 |
| 中性（Neutral）| 正常語速與語調 |
| 困惑 | 病人重複陳述、給予更多細節 |

## SER 的主要挑戰

### 1. 標註主觀性（Inter-annotator Agreement）
不同標註者對同一段語音的情緒判斷可能不同，IEMOCAP 的標註者一致性（Kappa）通常只有 0.5–0.7。這使得「正確答案」本身就存在不確定性。

### 2. 跨語言遷移
在英文資料集訓練的模型，直接應用於中文語音時準確率顯著下降。中文聲調（四聲）是語義的一部分，與情緒的聲學特徵高度重疊，增加了辨識難度。

### 3. 短語音片段的挑戰
短語音（<1秒）缺乏足夠的時間訊息（如語速變化、音調走向），SER 準確率通常較低。

### 4. 自然語音 vs 演員語音
IEMOCAP、RAVDESS 均是演員在特定情境下錄製的情緒語音，誇張程度較高。真實對話中的情緒通常更微妙，導致在實驗室資料集上訓練的模型在真實場景中表現下降。

### 5. 醫療情境的特殊情緒
醫學生的情緒狀態可能是「緊張但表現冷靜」、「疲憊」、「不確定」等複雜狀態，不容易對應到標準情緒類別。

## 與其他模組的關係

- **與 VAD 的關係**：SER 應在 VAD 過濾後才執行，避免對靜音片段進行無意義的情緒分析
- **與 ASR 的關係**：SER 和 ASR 可以平行執行，節省整體延遲
- **與 LLM 的關係**：SER 輸出作為額外上下文資訊注入 LLM Prompt，讓病人回應具有情境敏感性
- **與 TTS 的關係**：SER 結果可回饋給 TTS，控制病人語音的情感風格，形成完整的情緒感知循環
